# Чек-лист тестов — Yii2 Comments

Список тестов для фазы 2. Отмечайте `[x]`, когда тест написан и проходит.
`[!]` — тест написан и падает: он нашёл ошибку в приложении (причина — в конце колонки «Зачем»).
Найденные ошибки исправлены в ветках `fix/…`; такие тесты отмечены `[x]` с пометкой и тегом regression.

**Приоритет:** Высокий — блокирует сдачу, Средний — желательно, Низкий — если останется время.
